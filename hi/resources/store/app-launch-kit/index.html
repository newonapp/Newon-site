OVERVIEW

Building is not the same
as launching.

Many products finish building
and still stall before going live.

Accounts, policies, metadata, screenshots, QA,
announcement copy, early channels —
each item looks small until one missing piece delays ship day.

This kit binds product definition through post-launch review
into a single launch workflow.

MODULES

Launch work,
broken into modules.

01

PRODUCT DEFINITION

Lock idea, problem, user, and core value
on one page before launch.
Say clearly what you are shipping.

02

MVP SCOPE

Separate must-ship features from later work.
If scope drifts, ship day drifts with it.

03

PRE-LAUNCH CHECKLIST

Accounts, policies, analytics, test accounts —
the operational setup that must finish
before you go public.

04

APP STORE METADATA

Name, subtitle, description, keywords,
and screenshot structure —
the copy that lives on the store page.

05

QA CHECKLIST

Function, UI, devices, and edge cases
against a launch bar.
Remove “it mostly works.”

06

LAUNCH TIMELINE

Place pre-launch, day-of, and post-launch work
on a shared schedule.
Make ownership visible.

07

MARKETING STARTER

Minimum prep for social, landing,
and early-user channels
so launch and notice move together.

08

POST-LAUNCH REVIEW

Collect reviews, bugs, reactions, and next updates
right after ship.
Launch is the start of the next cycle.

HOW TO USE

How to use it.

  1. 01

    Write the ship sentence

    State what this store submission includes —
    and excludes — on the Product Definition sheet first.

  2. 02

    Keep only must-ship

    Use MVP Scope to cut features
    down to what must land on launch day.

  3. 03

    Fill store copy early

    Draft name, subtitle, description, and keywords
    in parallel with late-stage build work.

  4. 04

    Run QA against the launch bar

    Record pass/fail for devices, edge cases,
    payments, and onboarding on the checklist.

  5. 05

    Place day-of and week-after

    Put announcements, monitoring, and review response
    on the Timeline, then continue into the Review sheet.
