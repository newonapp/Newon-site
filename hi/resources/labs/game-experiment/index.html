QUESTION

Does remembered choice increase tension?

METHOD

SIGNAL

OUTCOME

THE QUESTION

If a game remembers prior player behavior,
does choice feel heavier and more immersive?

In choice-driven games, when past choices don't matter, decisions feel weightless.

WHY THIS EXPERIMENT

WHY THIS EXPERIMENT

PROBLEM

When past choices don't actually affect outcomes, decisions feel weightless.

HYPOTHESIS

If the game remembers behavior and references it later, players think more carefully about each choice.
