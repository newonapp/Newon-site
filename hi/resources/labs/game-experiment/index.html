THE QUESTION

If a game remembers prior player behavior,
does choice feel heavier and more immersive?

In choice-driven games, when past choices do not matter, decisions feel weightless. Choice without memory is decoration.

WHY THIS EXPERIMENT

How we frame the problem.

01

PROBLEM

When past choices do not actually affect outcomes, decisions feel weightless.
Players pick — but the game does not remember.

02

HYPOTHESIS

If the game remembers behavior and references it later, players think more carefully about each choice.
Tension can appear even in short sessions.

03
