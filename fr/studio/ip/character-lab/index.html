CHARACTER vs LOGO / ILLUSTRATION

Different starting points
than logo or illustration.

Logo identifies the brand. Character builds personality and user relationship. Illustration is a single scene asset. Character is a reusable system of personality, expression, pose, and rules.

01

LOGO

Brand identification.

02

CHARACTER

Personality and user relationship — a reusable system.

03

ILLUSTRATION

A single result for a specific scene.
