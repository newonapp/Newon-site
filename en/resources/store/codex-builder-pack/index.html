OVERVIEW

Draw the boundary of work
before chasing speed.

The wider the instruction,
the more an agent may touch unrelated files.

Repo analysis, task specs, multi-file change rules,
bug reproduction, review, validation, release prep —
each stage needs a place to stop.

This pack supplies those stop points
as prompts and checklists.

HOW TO USE

How to use it.

  1. 01

    Read the repo first

    Run Repository Analysis to summarize structure,
    entry points, and tests before any edit.

  2. 02

    Write a small task spec

    Put goal, success criteria, and off-limits areas
    on the Task Spec for a single cycle.

  3. 03

    Verify in the same cycle

    After Implementation Workflow,
    finish related tests and manual checks before the next task.

  4. 04

    Log multi-file scope

    When many files change, record intent and paths
    in the Change Scope Log, then run Review Prompt.

  5. 05

    Close with release prep

    Use Release Preparation for final validation
    and a release-note outline before deploy.
