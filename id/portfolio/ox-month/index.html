Overview

OX MONTH adalah

aplikasi untuk menandai hari tanpa log berat dan mengelola kebiasaan serta target bulanan.

Problem

Daily choices and logs should stay light — heavy apps feel like too much

Solution

Minimal UX focused on daily decisions and records

Product

A habit flow kept to essentials with O/X checks and monthly logs.

Mobile app, onboarding, logging flows, notifications, multilingual UI

Fitur utama

Cek hari ini

Catat hari dengan O/X secara sederhana Kebiasaan tanpa input rumit

Kebiasaan bulanan

Lihat alur bulan sekilas Konsistensi dan pola jelas

Target bulanan

Atur target bulan ini dan pantau progres

Template

Mulai cepat dengan template siap pakai

Statistik

Lihat rasio dan pola secara visual Pahami perilaku Anda

Pengingat

Agar tidak lupa mencatat pengingat membantu

Widget beranda

Tanpa membuka aplikasi cek dan tandai dengan cepat

UI / UX
