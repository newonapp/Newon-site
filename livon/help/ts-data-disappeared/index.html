저장한 내용이 사라졌어요

대부분 브라우저의 사이트 데이터가 지워졌거나, 다른 브라우저·다른 기기로 보고 있는 경우예요.

증상

어제까지 있던 저장 항목, 할 일, 글, 맞춤 설정이 보이지 않아요.

가능한 이유

  • 브라우저의 쿠키·사이트 데이터를 지웠어요(자동 삭제 설정 포함).
  • 다른 브라우저나 다른 기기로 접속했어요.
  • 사생활 보호 창에서 썼던 내용이에요.
  • 초기화나 삭제 버튼을 눌렀어요.

해결 방법

  1. 전에 쓰던 기기와 브라우저로 다시 열어 봐요.
  2. 브라우저의 ‘종료 시 사이트 데이터 삭제’ 설정을 꺼요.
  3. 서버에 사본이 없어서 지워진 내용은 복구할 수 없어요.

관련 도움말

  • 브라우저 기록을 지우면 어떻게 되나요?
  • 다른 기기에서는 왜 안 보이나요?
  • ‘저장이 막혀 있어요’ 안내는 무슨 뜻인가요?
