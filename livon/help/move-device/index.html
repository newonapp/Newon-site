다른 기기로 내용을 옮길 수 있나요?

아직 옮길 수 없어요. 자동으로 옮기는 기능도, 파일로 내보내고 불러오는 기능도 지금은 없어요.

새 기기에서는 맞춤 설정을 다시 고르고, 필요한 항목을 다시 저장해야 해요.

커뮤니티 글은 쓴 기기의 브라우저에만 남아요.
