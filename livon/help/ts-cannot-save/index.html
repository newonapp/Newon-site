저장이 안 돼요

브라우저가 저장을 막고 있거나 저장 공간이 가득 찼을 수 있어요.

증상

저장을 눌러도 남지 않거나, 새로고침하면 사라져요.

가능한 이유

  • 쿠키·사이트 데이터가 차단되어 있어요.
  • 사생활 보호(시크릿) 창을 쓰고 있어요.
  • 이미지가 큰 커뮤니티 글 때문에 저장 공간이 가득 찼어요.
  • 처음 저장할 때 뜨는 확인 창에서 ‘취소’를 눌렀어요.

해결 방법

  1. 브라우저 설정에서 이 사이트의 쿠키·사이트 데이터를 허용해요.
  2. 일반 창에서 다시 열어요.
  3. ‘저장 공간이 부족해 저장하지 못했습니다’가 보이면 이미지가 큰 글을 정리해요.
  4. 저장을 다시 누르고 ‘이 기기에 저장’을 선택해요.

관련 도움말

  • ‘저장이 막혀 있어요’ 안내는 무슨 뜻인가요?
  • ‘저장’은 어떻게 동작하나요?
  • 저장한 내용이 사라졌어요
