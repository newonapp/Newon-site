도움말 · 저장·데이터

‘저장이 막혀 있어요’ 안내는 무슨 뜻인가요?

브라우저 설정 때문에 LIVON이 내용을 보관할 수 없다는 뜻이에요. 쓰는 동안에는 동작하지만 창을 닫으면 사라져요.

쿠키·사이트 데이터를 차단했거나, 일부 앱 안의 브라우저처럼 저장을 허용하지 않는 환경에서 나타나요.

이때 LIVON은 내용을 창이 열려 있는 동안만 기억해요. 기능이 멈추지는 않아요.

이렇게 해 보세요

  1. 브라우저 설정에서 쿠키·사이트 데이터 차단을 해제해요.
  2. 사생활 보호(시크릿) 창이면 일반 창에서 다시 열어요.
  3. 앱 안에서 열었다면 기본 브라우저로 열어 보세요.
