NEWON LABS · IP · CHARACTER

Not one character —
can we build a scalable IP system?

A character is easy to leave as a single drawing.
Without expression, pose, personality, world rules, and usage guidelines,
it wobbles as it moves into product, content, and merch.

Character Lab is not an experiment in drawing one mascot.
It tests whether identity → form → expression → world → application
can become a reusable IP system.

Can one character remain the same presence
across many touchpoints?

THE QUESTION

Can one character become a reusable IP system
that extends to product, content, merch, and brand?

Characters are often designed once but hard to extend consistently across media. A look alone is not a system.

WHY THIS EXPERIMENT

How we frame the problem.

01

PROBLEM

Character design alone does not extend consistently across content and products.
Each channel becomes a different character.

02

HYPOTHESIS

Systematizing visual rules, personality, and expression first keeps consistency across media.
Guidelines create expansion speed.

03

EXPERIMENT

IDENTITY → FORM → EXPRESSION → WORLD → APPLICATION → IP
