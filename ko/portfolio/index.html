PROFILE

제품 하나가 만들어지는 전체 과정을 경험합니다.

Newon을 운영하며 모바일 앱과 디지털 제품을 직접 기획하고 개발합니다.

아이디어와 문제를 발견하는 단계부터 서비스 구조, UX/UI, 개발, 출시, 운영, 마케팅까지 제품이 실제 서비스가 되는 전 과정을 연결합니다. 하나의 역할에만 머무르기보다 제품 전체를 이해하고 빠르게 실행하는 방식으로 작업합니다.

CASE 01 TESTING

Review AI

CHALLENGE
앱·서비스 리뷰에서 개선 신호를 얼마나 빠르게 뽑을 수 있는가?
DECISION
구조화된 요약과 테마 클러스터링이면 수동 분류보다 빠르게 우선순위를 잡을 수 있다.
BUILD
리뷰 입력 → 테마 분류 → 요약 보드 프로토타입을 구축 중.
LEARN
키워드·감정 휴리스틱만으로도 반복 불만과 기능 요청을 빠르게 표면화할 수 있다. 정확도는 실제 모델 연결이 필요하다.

CASE 02 TESTING

Newon QR

CHALLENGE
작은 팀이 QR을 만들고 추적하는 데 정말 필요한 기능은 무엇인가?
DECISION
생성·목적지 변경·기본 스캔 추적이면 초기 수요를 확인할 수 있다.
BUILD
QR 생성기와 대시보드 프로토타입을 조립 중.
LEARN
생성 UX는 단순할수록 좋다. 추적 가치는 백엔드 없이 검증하기 어렵다.

CASE 03 RESEARCH

Character Lab

CHALLENGE
가짜 캐릭터를 올리지 않고, 검증된 IP만 공개할 수 있는가?
DECISION
작은 캐릭터 시스템부터 검증하면 브랜드 일관성을 지킬 수 있다.
BUILD
캐릭터 가이드라인·톤·사용 규칙 초안을 정리 중. 다운로드 가능한 에셋은 아직 없음.
LEARN
내부 캐릭터 컨셉 1종 검증 후 공개 여부 결정.
