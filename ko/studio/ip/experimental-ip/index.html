NEWON STUDIO · IP·EXPERIMENTAL IP

아직 없는 것을
작게 만들고 빠르게 확인합니다.

새로운 캐릭터, 세계관, 디지털 콘텐츠, 인터랙티브 아이디어와 브랜드 실험을 작은 프로토타입으로 빠르게 구현합니다.

완성된 답을 처음부터 정하는 대신 핵심 가설을 시각화하고 실제로 보여줄 수 있는 형태로 만든 뒤, 반응과 가능성을 확인하면서 다음 방향을 결정합니다.

단순한 아이디어 발상이 아니라
새로운 IP와 경험의 가능성을 실제 형태로 시험하는 창작 실험 과정입니다.

OVERVIEW

모든 IP가 처음부터
완성된 세계관으로 시작할 필요는 없습니다.

새로운 캐릭터나 콘텐츠 아이디어가 있어도 실제로 사람들이 관심을 가질지, 어떤 형태가 가장 적합할지, 어디까지 확장할 수 있을지는 처음부터 알기 어렵습니다.

그래서 큰 제작에 들어가기 전에 작은 실험이 필요합니다.

Newon Experimental IP는 Idea → Hypothesis → Concept → Prototype → Test → Learn → Next의 흐름으로 새로운 IP와 콘텐츠 경험을 검토합니다.

처음부터 완성된 대형 프로젝트를 만드는 것이 아니라 핵심 아이디어를 가장 작은 형태로 구현하고, 실제로 보여줄 수 있는 결과물로 만든 뒤 확장 가능성을 판단합니다.

PROBLEMS

이런 상황에서 Experimental IP가 필요합니다.

01

IDEA BUT NO FORM

아이디어는 있는데 어떤 형태로 만들어야 할지 모르겠습니다.

캐릭터, 콘텐츠, 서비스나 세계관 아이디어는 있지만 실제 결과물로 구체화되지 않은 경우.

02

TOO EARLY TO BUILD BIG

처음부터 크게 만들기에는 아직 이릅니다.

전체 애니메이션, 게임, 굿즈, 서비스 제작 전에 핵심 가능성을 먼저 확인하고 싶은 경우.

03

NO CLEAR FORMAT

콘텐츠 형식이 정해지지 않았습니다.

캐릭터 IP가 웹툰, 숏폼, 게임, 앱, Social Content 중 어떤 형태에 적합한지 탐색이 필요한 경우.

04

NEED DIFFERENTIATION

기존 콘텐츠와 다른 새로운 접근이 필요합니다.

브랜드나 제품이 기존 Campaign과 Content Format에서 벗어난 실험적 표현을 시도하고 싶은 경우.

05

IP EXPANSION

기존 캐릭터나 세계관을 새로운 방향으로 확장하고 싶습니다.

기존 IP를 새로운 플랫폼, Format 또는 Interactive Experience로 확장하기 전 가능성을 검토하고 싶은 경우.

06

CONCEPT VALIDATION

팀 안에서만 이야기하고 있습니다.

아이디어가 문서나 말로만 존재해 실제로 보면서 판단할 수 있는 Prototype이 필요한 경우.

07

NEW CULTURAL IDEA

새로운 문화적 포맷이나 경험을 실험하고 싶습니다.

디지털 문화, AI, Community, Game, Character, Social 등 여러 요소가 결합된 새로운 형태를 탐색하고 싶은 경우.

03

FAST

기존의 익숙한 형식을 반복하기보다 새로운 표현 가능성을 탐색합니다.

05

TESTABLE

검증 가능성

06

07

LEARNABLE

학습 가능성

성공 여부만 보는 것이 아니라 무엇을 배웠는지가 다음 단계로 이어져야 합니다.

08

BRAND / CULTURE FIT

맥락 적합성

WHAT WE DO

프로젝트에서 진행하는 작업.

01

IDEA FRAMING

아이디어 정의

무엇을 만들고 싶은지보다 왜 이 아이디어가 필요한지부터 정리합니다.

02

HYPOTHESIS

가설 설정

이 실험을 통해 무엇을 확인하고 싶은지 명확하게 정의합니다.

03

AUDIENCE / CONTEXT

사용자와 맥락

누가 이 아이디어를 경험하고 어떤 상황에서 접하게 될지 정리합니다.

04

CONCEPT DIRECTION

컨셉 방향

05

IP STRUCTURE

IP 구조

필요한 프로젝트에서는 Character, World, Relationship, Story, Rule 등 기본 구조를 정리합니다.

06

FORMAT EXPLORATION

포맷 탐색

Short-form, Interactive, Game, Social, Web, Character, Digital Collectible 등 어떤 형태가 적합한지 검토합니다.

07

PROTOTYPE

프로토타입

핵심 아이디어를 가장 빠르게 보여줄 수 있는 형태로 구현합니다.

08

PILOT CONTENT

파일럿 콘텐츠

필요한 경우 실제 공개 또는 테스트 가능한 소규모 콘텐츠를 제작합니다.

09

APPLICATION SCENARIO

확장 시나리오

아이디어가 이후 어떤 채널, 콘텐츠 또는 제품으로 확장될 수 있는지 정리합니다.

10

NEXT STEP

다음 단계

실험 결과를 기준으로 Continue / Refine / Pivot / Stop 등 다음 방향을 제안합니다.

다양한 형태의 IP 실험이 가능합니다.

모든 항목이 기본 범위에 포함되지는 않습니다. 프로젝트에 따라 필요한 방향을 선택합니다.

01

CHARACTER CONCEPT

캐릭터 실험

새로운 Character Personality와 Visual Direction을 빠르게 프로토타이핑.

02

WORLD CONCEPT

새로운 World Rule, Setting과 Relationship 구조를 작은 범위로 구성.

03

SHORT-FORM IP

숏폼 IP

짧은 영상이나 반복형 Social Format으로 Character / Story의 가능성을 검토.

04

INTERACTIVE IP

인터랙티브 IP

웹, 앱 또는 간단한 Digital Interaction을 통해 사용자가 직접 참여하는 IP 경험.

05

GAME CONCEPT

06

07

DIGITAL OBJECT

08

CULTURAL FORMAT

새로운 콘텐츠 포맷

Meme, Community Participation, Story Format 등 새로운 문화적 경험을 실험.

IDEA → IP · PROTOTYPE

아이디어와 IP는 다르고,
Prototype 수준도 달라집니다.

Experimental IP는 단순히 좋은 아이디어를 만드는 것이 아니라 반복해서 확장할 수 있는 구조가 있는지를 확인합니다.

모든 프로젝트에서 최고 수준의 Interactive Prototype까지 진행하는 것이 아니며 실험 목적과 예산에 따라 적절한 수준을 선택합니다.

처음부터 수십 명의 Character와 복잡한 Lore를 만드는 대신 핵심 Character + Rule + Conflict를 중심으로 가능성을 검토할 수 있습니다.

01

IDEA → CHARACTER / WORLD

흥미로운 발상에서 반복해서 보여줄 수 있는 존재와 설정으로.

02

RULE · FORMAT

일관된 행동 기준과 사람들이 실제로 경험할 콘텐츠 형태.

03

REPEATABILITY · EXPANSION

한 번으로 끝나지 않는 구조와 다른 채널·제품으로의 발전 가능성.

04

LEVEL 01 — CONCEPT

Mood, Story, Character, Visual 등 Idea를 빠르게 정리한 Concept Prototype.

05

LEVEL 02 — VISUAL

Character Sheet, Key Visual, Story Scene 등 눈으로 확인할 수 있는 Visual Prototype.

06

LEVEL 03 — CONTENT

Short-form, Social Post, Mini Episode 등 실제 콘텐츠에 가까운 Pilot.

07

LEVEL 04 — INTERACTIVE

간단한 Web / App / Game Interaction 등 사용자가 직접 경험할 수 있는 Prototype.

08

CHARACTER · MOTIVATION

핵심 Personality / Visual과 캐릭터가 원하는 것.

09

CONFLICT · WORLD RULE

이야기를 만들 충돌과 세계에서 유지되는 규칙.

10

RELATIONSHIP · CONTENT HOOK

관계 구조와 사람들이 반복해서 관심을 가질 이야기의 시작점.

AI · INTERACTIVE · FORMAT

AI, Interactive, Social, Game과
새로운 Format을 작게 실험합니다.

AI 출력의 품질, 일관성, 안전성, 외부 API 비용과 정책은 실제 구현 환경에 따라 달라질 수 있습니다.

모든 Interaction이 기본 범위에 포함되지는 않습니다.

Social-first IP는 작은 콘텐츠 단위로 Character와 Format의 반복 가능성을 확인할 수 있지만 특정 조회수, 팔로워, 바이럴 성과를 보장하지 않습니다.

Game Concept은 Full Game Development가 아니라 핵심 재미와 IP 연결 가능성을 확인하는 Prototype입니다.

좋은 Format은 매번 처음부터 기획하지 않아도 새로운 콘텐츠를 계속 만들 수 있는 반복 규칙을 갖습니다.

01

AI CHARACTER · MEMORY

대화·상황 반응 Character와 이전 Interaction을 연결하는 Experience.

02

PERSONALIZED · GENERATIVE

선택에 따라 달라지는 Story와 생성형 결과를 IP 경험의 일부로 활용.

03

DYNAMIC WORLD · CO-CREATION

입력·행동에 따라 변하는 World와 사용자 참여형 제작 구조.

04

INTERACTIVE EXAMPLES

Choice Story, Mini Game, Personality Test, Character Chat, Collection, Challenge, Community Vote 등 — 범위에 따라 선택.

05

SOCIAL-FIRST FLOW

Character / Idea → Short Content → Reaction → Repeatable Format → Community → Expansion.

06

SOCIAL FORMATS

Short-form, Meme, Reaction Character, Mini Episode, Daily Question, Community Choice, Character POV, Behind Story.

07

GAME CORE LOOP

반복 행동, Rule, Goal, Feedback, Character / World 연결과 Replay 이유.

08

CONTENT FORMATS

Daily, Episodic, Choice, Collection, Challenge, Community 등 반복 가능한 Format 규칙.

09

EXPANSION MAP

Prototype → Social / Content → Character / Story → Interactive → Game / App → Merch → Collaboration. 모든 실험이 이 단계까지 가지 않습니다.

실험의 목적은 성공을 미리 보장하는 것이 아니라 작은 비용과 범위로 아이디어를 실제 형태로 만들어 다음 의사결정에 필요한 학습을 얻는 것입니다.

PROCESS

프로젝트는 이렇게 진행됩니다.

01

DISCOVER

02

SCOPE DIFFERENCE

Character Lab, Campaign,
Product Design과 시작점이 다릅니다.

Character Lab은 이미 Character가 필요하다는 목적이 명확할 때 Personality, Visual, Expression, Pose와 Usage System을 전문적으로 구축합니다. Experimental IP는 아직 Character, World, Content Format, Game, Interactive 등 어떤 형태가 적합한지 자체를 탐색하고 실험하는 단계입니다. 가능성이 확인되면 Character Lab으로 확장할 수 있습니다.

Campaign이 “어떻게 알릴 것인가”에 가깝다면 Experimental IP는 “무엇을 새롭게 만들 수 있는가”에 더 가깝습니다.

Product Design은 사용자 문제를 해결하는 실제 Digital Product의 기능·구조·UX를 설계합니다. Experimental IP는 문화적 아이디어, Character, Story, Interactive Content 등 창작적이고 탐색적인 경험을 실험합니다. AI Character App, Interactive Story Product, Character-based Game, Community-driven IP Platform처럼 둘이 결합되는 프로젝트도 가능합니다.
