CHARACTER vs LOGO / ILLUSTRATION

로고·일러스트와
시작점이 다릅니다.

Logo는 브랜드 식별. Character는 브랜드 Personality와 사용자 관계. Illustration은 특정 장면의 단일 결과물. Character는 Personality / Expression / Pose / Rule을 정의한 반복 사용 System입니다.

01

LOGO

브랜드 식별.

02

CHARACTER

Personality와 사용자 관계 형성. 반복 사용 System.

03

ILLUSTRATION

특정 장면을 위한 단일 결과물.
