확장 가능한 IP 시스템을 만들 수 있을까?

캐릭터는 그림 한 장으로 끝나기 쉽습니다.
표정, 포즈, 성격, 세계관, 사용 규칙이 없으면
제품·콘텐츠·굿즈로 갈수록 흔들립니다.

Character Lab은 마스코트 한 점을 그리는 실험이 아닙니다.
정체성 → 형태 → 표현 → 세계 → 적용까지
재사용 가능한 IP 시스템으로 묶는지를 봅니다.

한 번 만든 캐릭터가
여러 접점에서 같은 존재로 남을 수 있는가.

재사용 가능한 IP 시스템으로 만들 수 있을까?

캐릭터를 만들어도 다른 매체에서 일관되게 확장하기 어렵습니다. 외형만 있으면 시스템은 아닙니다.

왜 이 실험인가

문제를 이렇게 봅니다.

01

PROBLEM

캐릭터 디자인은 만들어도
다른 콘텐츠와 제품에서 일관되게 확장하기 어렵습니다.
채널마다 다른 캐릭터가 됩니다.

02

HYPOTHESIS

캐릭터의 시각적 규칙과 성격, 표현 체계를 먼저 시스템화하면
다양한 매체에서도 일관성을 유지할 수 있습니다.
가이드가 확장 속도를 만듭니다.

03

EXPERIMENT

IDENTITY → FORM → EXPRESSION → WORLD → APPLICATION → IP
