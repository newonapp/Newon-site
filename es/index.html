❓ Preguntas frecuentes

¿Puedo usar la aplicación gratis?

Sí. Las funciones básicas son de uso gratuito. Consulte la sección Premium para conocer funciones adicionales opcionales.

¿Qué dispositivos son compatibles?

La aplicación está disponible para iOS y Android a través de los enlaces App Store y Google Play.

¿Cómo se manejan mis datos?

Las prácticas de datos pueden variar según la aplicación y la función. Revise la Política de privacidad para obtener más detalles.

¿Qué incluye Premium?

Las funciones Premium que ofrece esta aplicación se enumeran en la sección Premium de esta página.

¿Dónde gestiono mi suscripción?

Gestiona compras, renovaciones y cancelaciones a través de la cuenta App Store o Google Play utilizada para el pago.

¿Cómo elimino mi cuenta y mis datos?

Utilice la página de eliminación de cuenta específica de la aplicación vinculada aquí para obtener instrucciones de eliminación.

¿Cómo puedo contactar con el soporte?

Para obtener ayuda, comuníquese con newon@newon.app.
