2026-09-26. 운영 배포 전 로컬 구현이다. 기존 공통 서비스 상세와 흑백 카드 디자인을 확장한다.

## 실행

기존 개발 서버에서 `/livon/#stage-20`을 연다. 주요 상세 주소는 `/livon/#life-service-service-20-01`(예산), `...-08`(취업 체크리스트), `...-12`(제품 비교)다. 기존 모든 카드의 ID를 유지한다. `npm run test:livon`으로 자동 테스트를 실행한다. 정적 배포에는 `node scripts/publish-site.mjs`가 청년 스크립트를 포함해 복사한다.

## 변경

신규 `service-youth-data.js`는 분야·폼·체크리스트·빈 공식 피드와 향후 API 스키마를 정의한다. `service-youth.js`는 공통 `LivonServices.ui`를 재사용하는 청년 상세 확장이다. 별도 라우터·저장 플랫폼·전문가 DB는 만들지 않았다.

수정: `life-data.js`, `service-details.js`, `livon-platform.js`, `index.html`, `life-page.css`, `tests/livon/services.test.mjs`.

15개 서비스의 type/cta/detail을 검수했고, dataRequirements로 local/api/partner 의존성을 구분한다. 이력서·면접의 잘못된 예산 CTA/목적지는 취업 준비/할 일로 수정했다. 채용·멘토링·주거 지원·이사·제품 비교·상담·생활 서비스 CTA도 목적에 맞게 수정했다.

## 실제 작동 범위

- 24개 금액 입력으로 생활비·저축 계획 계산. 총수입에서 고정비·생활비·월 저축 목표를 뺀 잔액과 목표 기준 저축률을 표시한다. 비상금 등 누적 목표는 월 저축액에 중복 합산하지 않는다. 수입 0은 저축률 계산 불가, 부족한 잔액은 조정 안내한다.
- 기존 내 생활 월 예산에는 고정비+생활비를 명시적 저장 버튼으로 반영한다. 실제 거래 내역을 생성하지 않는다.
- 이력서/자소서/포트폴리오/면접, 이사/입주 체크리스트. 저장 시 안정적인 ID로 갱신하고 다른 내 생활 기록을 유지한다.
- 주거/서비스 조건 입력, 직접 입력한 2~3개 제품 비교. 조건과 비교는 기존 저장 항목의 data 필드로 보존한다. 작업 중 폼 초안은 sessionStorage를 사용한다.
- 지원제도·채용·대학은 필터와 미연결 안내, 공식 출처 연결만 제공한다. 날짜·금액·실제 모집 항목을 만들지 않는다.
- 여행·취미는 기존 오늘의 발견 콘텐츠를 재사용한다. 운영 날짜가 확인되지 않았으면 날짜 필터를 적용하지 못했다고 명시한다. 실제 예약을 만들지 않는다.
- 대학/전공/편입 탭에서 기존 전공 가이드 예시와 검색/비교를 재사용한다. 실제 학교·입시 DB로 표시하지 않는다.
- 교육/전문가/기관/생활 서비스는 기존 탐색으로 연결한다. 일정 CTA는 기존 내 생활의 직접 입력 화면으로 연결한다.
- AI는 선택한 서비스·연령·입력 필드명과 값·완료 체크를 초안으로 전달한다. 사용자 전송 전에는 AI 서버를 호출하지 않는다. 서버 API 키는 기존 서버 전용 환경변수만 사용한다.

## 검증

24개 자동 테스트 통과: 기존 AI 13개, 공통 서비스 8개, 청년 3개. 99개 서비스 회귀, 예산 정상/적자/0수입/비정상 입력, 15개 청년 상세 생성, 빈 공식 피드 검증 포함.

실제 브라우저에서 15개 카드의 표시된 CTA 주소로 모든 상세 제목과 폼을 확인했다. 수입 250만원·고정비 60만원·생활비 40만원·저축 50만원 입력은 잔액 100만원·저축률 20%를 출력했다. 취업 체크리스트 반복 저장·탭 이동·AI 맥락 전달, 제품 비교·저장·새로고침 복원을 확인했다. 자격증 검색은 탐색의 큐넷 교육 결과로 연결됐다. 뒤로가기, 전공 상세, 기존 10대 플래너, 내 생활 저장함 표시, 오류 로그 없음 확인.

390px 모바일 폼/비교 1열, 768px 태블릿 가로 넘침 없음, 1280px 데스크톱 상세 시각 확인. 임시 viewport는 원복했다. 테스트용 취업 체크리스트와 제품 비교 목록은 로컬 브라우저 저장함에 남아 있다. 실제 운영 배포/외부 실데이터/예약·결제는 검증하지 않았다.
