# LIVON 라이프 스테이지 서비스 상세 구현

## 구조 및 파일

기존 정적 HTML/CSS/JavaScript SPA와 hash 라우터를 유지했다. React나 별도 상세 앱은 추가하지 않았다.

수정: `livon/life-data.js`(99개 서비스 메타데이터), `life-page.js`(공통 카드/상세 라우팅 및 새로고침 초기화), `life-page.css`(기존 흑백 컴포넌트 기반 카드·상세·폼 반응형), `index.html`(사용자용 추천 문구 및 스크립트 로드), `livon-platform.js`(공통 저장 title/lifeStage/savedAt), `ai-page.js`(전달받은 내용을 자동 전송하지 않고 초안으로 표시).

신규: `livon/service-details-data.js`(과목/전공/직업 가이드 및 향후 데이터 스키마), `livon/service-details.js`(상세/플래너/필터/비교/저장/공유/AI 전달), `tests/livon/services.test.mjs`(8개 기능 테스트), 이 문서.

## 서비스 연결

10대 주요 6개:
- 학습 플래너 → 학년·목적·과목·목표·날짜·시간·요일 입력 → 7일 계획, 진행률, D-Day → 내 생활 체크리스트. 규칙 기반 시간 분배이며 성적 예측이 아니다.
- 진로 멘토링 → 상담 주제 → 기존 탐색의 전문가 유형 검색.
- 취미 클래스 → 동반자·장소·비용·시간·관심 필터 → 기존 오늘의 발견 콘텐츠 상세. 조건을 확인할 수 없는 콘텐츠는 해당 조건 결과에서 제외.
- 과목별 학습 정보 → 6개 과목 로드맵 → EBS·플래너·AI.
- 진학·전공 탐색 → 일반 가이드 예시 3개 검색·상세·최대 3개 비교·저장 → 공식 입시정보.
- 직업·적성 탐색 → 일반 가이드 예시 2개 검색·상세·저장 → 탐색 교육/전문가·커리어넷·AI.

10~70대 총 99개에 고유 id/type/cta/detail/lifeStage/destination을 적용했다. 기존 서비스명·설명·기능의 의미를 유지했다. Tool 13개, Guide 41개, Expert 11개, Discovery 34개. AI 유형 렌더러도 지원하지만 기존 서비스 중 AI 전용으로 임의 변경한 카드는 없다. 각 상세의 보조 AI 버튼으로 연결한다.

20~70대는 동일한 공통 상세를 거쳐 기존 내 생활 도구, 탐색 분야, 오늘의 발견 또는 Ongil 등 원래 의미에 맞는 목적지로 연결한다. 새로운 기능 추가는 데이터 항목과 필요한 detail renderer를 추가하는 방식이다.

## 저장·AI·URL

기존 `LivonPlatform` 저장을 사용하며 저장함은 `#ml-saved`다. 서비스·전공·직업은 안정적인 ID로 중복을 막는다. 학습 계획은 기존 `livon.mlStore.v1.checklists`에 추가하며 기존 할 일 등 다른 배열을 유지한다. 같은 계획을 반복 저장해도 중복되지 않는다. 저장된 계획의 체크 변경은 반영된다. 저장은 해당 브라우저 기기 기준이며 로그인 계정 동기화는 아직 없다.

AI 버튼은 서비스명·연령대·선택한 정보 또는 학습 입력을 세션 초안으로 전달한다. 사용자가 전송할 때 기존 `/api/livon/chat`이 호출된다. API 키는 클라이언트에 추가하지 않았다. 실제 생성에는 서버 환경변수와 AI 백엔드 배포가 필요하다.

URL 예시:
- `/livon/#life-service-study-planner`
- `/livon/#life-service-major-explorer/majors/software`
- `/livon/#life-service-career-explorer/careers/developer`

기존 hash 라우팅과 browser history를 사용한다. 직접 접속·새로고침에서도 상세를 초기화한다. 공유는 현재 상세 URL을 사용하고 Web Share가 없는 환경에서는 링크 복사를 사용한다.

## 디자인 보완

흑백 색상·기존 헤더/탭/타이포그래피/버튼 체계를 유지했다. 카드의 주 행동은 넓은 버튼 하나, 보조 행동은 가벼운 하단 행으로 구분했다. 상세는 경로·제목·추천 근거/기능·사용 영역·저장/공유 순서로 정돈했다. 입력 폼 간격, 목록 간격, 체크 완료 표시, 키보드 포커스와 reduced-motion 대응을 추가했다. 700px 이하 상세 폼/결과는 1열이다.

## 검증

`npm run test:livon`: 21개 통과(기존 AI 13개 + 서비스 8개). 서비스 테스트는 99개 ID/유형/CTA/상세 생성, 저장 토글, 계획 시간 분배·반복 저장·기존 데이터 보존·진행률, 잘못된 입력, 공유 상세 URL, AI 초안, 비교/삭제, 잘못된 주소/입력 이스케이프를 검증한다. 외부 OpenAI 호출 없이 테스트한다.

실제 브라우저에서 학습 계획 생성 → 진행률 10% → 반복 저장 → 내 생활 체크리스트 1개를 확인했다. 뒤로가기와 AI 초안 전달, 취업 주제 → 전문가 검색의 고용24 결과, 베이킹 필터 결과, 수학 과목 전환, 전공 검색/상세/비교, 전공 상세 새로고침, 직업 상세를 확인했다. 모바일 390px에서 상세 화면 가로 넘침이 없음을 확인했다. 기능 검증용 학습 계획 1개는 로컬 내 생활에 남아 있다.

최종 디자인 보완 후 서비스 테스트 8개가 다시 통과했다. 데스크톱에서 추천 카드와 상세 화면을 시각 확인하고 고정 헤더 겹침을 수정했다. 모바일 390px에서 카드·폼 1열, 태블릿 768px에서 폼 2열 및 가로 넘침 없음(문서 너비=뷰포트 너비)을 확인했다. 20~70대 카드는 각각 15/15/14/15/14/14개가 표시됐다. 오늘의 발견·내 생활·탐색·커뮤니티·AI 메뉴가 렌더링되고 브라우저 오류 로그가 없었다. 이는 메뉴 이동 회귀 확인이며 모든 기존 기능의 완전한 회귀 검증이나 실제 운영 배포 검증은 아니다.

## 미연결 데이터와 다음 단계

개인 전문가 목록·검증된 경력·후기·가격·상담 가능 시간, 실제 클래스 업체·일정·예약, 대학/전공 전체 DB·입시 일정, 직업 전체 DB·검사 API는 연결되지 않았다. 해당 화면에 이를 명시하고 공식 정보로 연결한다. 전공·직업 항목은 명시적인 일반 가이드 예시이며 실제 학교/입시 데이터로 표시하지 않는다.

향후 검증된 공공/공식 데이터 adapter, 출처·확인일 관리, 계정 기반 저장 API와 사용자별 권한, 전문가/예약 운영체계가 필요하다. 이번 변경은 로컬 작업이며 newon.app 운영 사이트에 자동 배포하지 않았다.
