# LivOn · Ongil 웹 기능 → 앱 이전 매핑 및 검증 계획

조사 기준: 저장소 코드 정적 조사(2026-10-17). **실제 운영 서버 상태, 실기기 동작, 앱 저장소 코드는 확인하지 못했다(미검증).**
"종료 가능" 열은 모두 **아니오(앱 이전 미확인)** 이다. 아래 검증이 끝나기 전에는 어떤 항목도 종료하지 않는다.

## A. LivOn (`/livon/`, 한국어 전용, 해시 라우트)

| 웹 기능 | 데이터/API | 앱에서 필요한 것 | 검증 방법 | 종료 가능 |
|---|---|---|---|---|
| 홈·Today's Discovery(34개) | 정적 콘텐츠 | 동일 콘텐츠 제공 | 콘텐츠 수·링크 대조 | 아니오 |
| Life Stage(7단계·228 주제·34 인생사건·99 서비스) | 정적 데이터 | 동일 구조 이전 | 항목 수 대조 | 아니오 |
| My Life: 캘린더·할 일·목표·루틴·저널·기록·저장·예약 기록·가계·건강 기록·프로젝트·주간 리포트 | localStorage(`livon.mlStore.v1` 등) | 앱 로컬 저장 + 웹 데이터 가져오기 | **JSON 내보내기 → 앱 가져오기 왕복 테스트**, 항목 수 대조 | 아니오 |
| 데이터 내보내기/전체 삭제 | 로컬 | 앱 동등 기능 | 내보내기 파일 호환성 확인 | 아니오 |
| Explore(28개)·검색·비교·주변 검색 | `GET /api/livon/data`(청년센터, 기업마당, Kakao Local, TourAPI, 평생교육, 세무사, 고용24 프록시) | 앱이 같은 API 호출 또는 대체 제공 | 제공기관별 응답 비교, 키·할당량 확인 | 아니오 |
| Community | 로컬 전용 | 앱 정책 결정 | 이전 대상 여부 결정 | 아니오 |
| LIVON AI | `POST /api/livon/chat`(OPENAI_API_KEY, Upstash 제한, 응급 문구 하드코딩) | 앱 AI 동등 기능 + 응급 안내 유지 | 응급 문구 동일성, 속도 제한 테스트 | 아니오 |
| 도움말(68) · 온보딩/개인화 · 접근성 | 정적/로컬 | 앱 동등 | 항목 대조, 접근성 점검 | 아니오 |
| 정적 SEO 페이지(`/livon/life/…`, `/today/…`, `/help/`, `/life-events/`) | 정적 | **소개·검색 유입용으로 유지 가능** | — | 유지 |
| 계정 동기화(`/api/livon/userdata`) | PostgreSQL 표 정의만 있음, 운영 꺼짐 | 현재 익명·로컬 우선 유지 | — | 해당 없음 |

LivOn 원칙: **무료·익명 이용 유지**(계정 강제 금지).

## B. Ongil (`/ongil-start/`, 해시 라우트)

| 웹 기능 | 데이터/API | 앱에서 필요한 것 | 검증 방법 | 종료 가능 |
|---|---|---|---|---|
| 홈 · 온보딩 · 글자 크기 접근성 | 로컬 | 앱 동등 | 항목 대조 | 아니오 |
| My Life(일정·할 일·루틴·가계·일기·메모·수면) | localStorage `ongil.v1.<collection>` | 앱 이전 + 데이터 가져오기 | 컬렉션별 왕복 테스트 | 아니오 |
| 건강·안전(진료 일정, 측정, 비상연락처=`tel:`) | 로컬(`private/health` 등급은 동기화 금지) | 앱 동등. 비상 연락 기능 신뢰성 확보 | 실기기 전화 연결 테스트 | 아니오 |
| 가족(V1 로컬 모의, V2 서버 코드 비활성) | `/api/ongil/family`(기본 차단: `ONGIL_FAMILY_REMOTE_ENABLED`, DB, Newon+ 토큰) | 앱 가족 기능 설계 | 서버 배포 여부 확인 필요 | 아니오 |
| 돌봄(시설 검색만) · 즐기기 | `GET /api/livon/data` | 앱 동등 | 응답 비교 | 아니오 |
| 커뮤니티(자리표시) · 스토어(비어 있음) | 로컬 | 이전 불필요 가능 | 실제 사용 여부 확인 후 판단 | 아니오 |
| 도우미(규칙 기반, LLM 없음) | 로컬 | 앱 동등 | 규칙 동일성 | 아니오 |
| 숨김 `#admin` | 로컬 | 별도 판단 | 용도 확인 | 아니오 |

Ongil에는 긴급 알림·푸시, 예약, 결제, 판매자 기능이 웹에 **없다.** 앱 이전 시에도 새 기능으로 광고하지 않는다.

## C. 단계별 진행

1. **조사 확정**: 운영 API 상태·환경 변수·실제 사용자 데이터 존재 여부 확인(운영 접근 권한 필요).
2. **앱 저장소 확인**: LivOn·Ongil 앱 저장소 위치와 현재 구현 수준 보고.
3. **기능별 이전 구현**: 앱 저장소에서 별도 안전 개발 단계로 진행(이 저장소 범위 아님).
4. **데이터 이전 검증**: 내보내기/가져오기 왕복, 항목 수·내용 일치, 롤백 방법 확인.
5. **기능 단위 게이트 통과 후** `webStart`를 `transition → app-download`로 전환(소개 페이지는 유지).
6. **웹 UI 종료**: 승인 후 UI만 소개 페이지로 대체. API·DB·사용자 데이터·공통 코드는 별도 승인 전까지 보존.

## D. 롤백

`webStart`를 `transition`으로 되돌리면 "시작하기" 진입점이 복원된다. 웹 앱 코드와 데이터를 지우지 않으므로 롤백은 설정 변경만으로 가능하다.
