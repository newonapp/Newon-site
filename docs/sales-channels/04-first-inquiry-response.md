# 첫 문의 답변 초안

**문의 예시**  
「iOS/Android 앱 MVP 제작 문의드립니다. 로그인, 프로필, 게시판, 푸시 알림, 관리자 페이지가 필요합니다. 예산과 기간이 궁금합니다.」

**채널:** 이메일 / 크몽 / 위시캣 / 웹 문의 — 동일 취지로 사용.  
**플랫폼 결제 시:** 해당 플랫폼 정책 우선. Newon 직접 계약 문서와 이중 청구되지 않게 경로를 하나로.

---

## 1차 답변 (복사용)

안녕하세요, Newon입니다.  
앱 MVP 문의해 주셔서 감사합니다.

요청하신 범위는 **iOS/Android 앱 MVP**로,  
**로그인 · 프로필 · 게시판 · 푸시 알림 · 관리자 페이지**가 포함된 형태로 이해했습니다.  
해당 범위의 제작은 **가능**합니다. (보통 Flutter 크로스플랫폼으로 진행합니다.)

예산·기간은 기능 깊이·디자인 유무·서버/배포 포함 여부에 따라 달라져,  
**요구사항을 확인한 뒤 견적·일정으로 안내**드립니다.  
공개 사이트의 앱/MVP **시작가**는 참고용이며 **확정가가 아닙니다.**

먼저 아래만 알려주시면 1차 범위 감과 다음 단계를 안내하겠습니다.

1. iOS / Android / 둘 다 중 어느 쪽인가요?  
2. 디자인(Figma 등)이 이미 있으신가요, 아니면 UI도 함께인가요?  
3. 게시판은 텍스트 위주인지, 이미지·댓글까지 필요한지요?  
4. 푸시·관리자는 “필수”인가요, 1차 MVP에서 빼도 되는 항목이 있나요?  
5. 서버/호스팅·도메인·스토어 계정은 고객 측 소유로 진행해도 될까요?  
6. 희망 일정(예: N주 이내)과 예산 감이 있으시면 대략만이라도 부탁드립니다.  
7. 스토어 출시(제출·심사)까지 포함이 필요하신가요?

답변 주시면 **요구사항 정리 → 견적 → Scope(작업범위서)** 순으로 진행합니다.  
더 자세한 항목은 이후 `docs/client-projects/01-requirements-questionnaire.md` 체크리스트로 맞춰 드리겠습니다.

감사합니다.  
Newon

## 후속 (상세 질문)

1차 답이 오면:

1. `01-requirements-questionnaire.md` 해당 문항만 발췌 전송  
2. 범위 확정 후 `02-quote-template.md`로 견적  
3. 합의 시 `03-scope-of-work.md` → Go/No-Go(`09`) → (직접 계약 시 `10`) → 착수(`05`)

크몽/위시캣 **플랫폼 계약만** 쓰는 경우: 플랫폼 계약이 우선, SoW는 범위·수정 합의용으로 첨부.
