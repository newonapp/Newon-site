# 위시캣 지원 메시지 템플릿

**용도:** 프로젝트 지원 시 2–3분 내 수정 후 발송.  
**원칙:** 요구사항 확인 전 **확정 견적·확정 일정 약속 금지**. 미수행 경험·허위 성과 금지. AI 도구 등 내부 작업 방식은 넣지 않음.
