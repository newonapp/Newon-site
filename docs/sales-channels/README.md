## 운영 원칙

1. **가격:** 레포·공개 사이트의 **시작가·패키지 참고값**만 사용. `~부터`는 확정가가 아님. 최종은 Scope 확인 후 `docs/client-projects/02-quote-template.md`로 확정.
2. **프로세스:** 채널 문의 → 1차 답변 → [`01` 요구사항](../client-projects/01-requirements-questionnaire.md) → [`02` 견적](../client-projects/02-quote-template.md) → [`03` SoW](../client-projects/03-scope-of-work.md) → …
3. **플랫폼 결제/계약:** 크몽·위시캣 **플랫폼 정책·에스크로가 우선**. Newon 직접 합의(`10`)는 플랫폼 외 거래 또는 플랫폼이 허용하는 경우에만.
4. **Design Only** (Studio UI/UX·Brand)는 **개발(BUILD)과 별도**. 디자인 견적에 개발이 자동 포함되지 않음.
5. 허위 후기·성과·고객·기술 기재 금지. 포트폴리오는 공개 사이트 `/portfolio/` 근거만.

이 폴더는 Client Ops 템플릿을 대체하지 않습니다.
