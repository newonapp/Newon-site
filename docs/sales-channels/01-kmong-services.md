# 크몽용 서비스 상품 자료 (초안)

**용도:** 크몽 서비스 등록 시 복사·수정용.  
**근거:** Newon Business 공개 시작가, `admin/quote-packages.json`, `admin/pricing.json`, `docs/client-projects/*`, 포트폴리오.  
**가격 고지:** 아래 금액은 **참고 시작가**입니다. **확정가가 아닙니다.** 요구사항·Scope 확인 후 견적으로 확정합니다.  
공개 페이지·패키지 JSON·로케일 표기 사이에 **시작가 숫자가 다를 수 있습니다.** 충돌 시 **「Scope 확인 후 최종 견적」**으로 안내하고, 임의로 한 숫자를 확정가로 쓰지 마세요.

**플랫폼 정책:** 크몽 내 결제·계약·정산은 **크몽 정책 우선**. Newon Client Ops 문서(`02`/`03`/`10`)는 범위·수정·납품 합의에 사용. 이중 청구·이중 계약이 되지 않게 경로를 하나로 정합니다.

**공통 수정 정책 (Client Ops):** 범위 내 기본 수정 **2회**(취합 피드백 1묶음=1회). Newon 구현 오류는 차감 없음. 신규 기능·구조 변경은 Change Request. 상세 → `docs/client-projects/06-change-request-policy.md`.  
**납품 후:** 인수 확인 다음날부터 **30일** Newon 구현 오류 무상 대응(SLA/24h 아님). 이후 유지보수는 별도.

**외부 비용:** 도메인·서버·Cloud·API·SMS·스토어 개발자 계정 등은 **제작비와 별도, 고객 부담이 기본**.

## A. 앱 MVP 개발

### 서비스 제목 (예시)
iOS/Android 앱 MVP 개발 — Flutter 크로스플랫폼

### 한 줄 소개
로그인·프로필·게시·알림·간단 관리자까지, 출시 가능한 앱 MVP를 기획·UI·구현까지 함께합니다.

### 고객 대상
- 아이디어~기획 단계의 스타트업·1인 사업·브랜드
- 스토어 출시를 목표로 하는 첫 앱/프로토타입 이후 MVP

### 제작 가능 범위
- Flutter 기반 iOS / Android (크로스플랫폼)
- 기본 UI, 핵심 화면·플로우, Backend/API 연동(합의 범위)
- (옵션) 간단 관리자 웹, 푸시, AI API 연동 등 — **별도 Scope**

### 핵심 기능 예시
회원가입/로그인, 프로필, 피드·게시판, 푸시 알림, 파일 업로드, 간단 Admin, 외부 API 연동

### 지원 플랫폼
iOS · Android (Flutter). 웹 동시 출시는 별도 합의.

### 개발 방식
요구사항 정리 → Scope/견적 → 기획·UI → 개발 → 내부 QA → 고객 검수 → 수정 → 납품

### 제공 결과물 (합의 범위)
소스·합의된 프로젝트 문서·빌드 관련 파일·합의된 설정/파라미터. 스토어 제출은 **포함 여부를 SoW에 명시**.

### 작업 진행 단계
상담 → 요구사항(`01`) → 견적(`02`) → SoW(`03`) → 계약/승인 → 착수 → 중간 공유(`11`) → QA(`07`) → 인수(`08`)

### 예상 기간 (참고)
| 참고 패키지 (`quote-packages`) | 참고 시작 금액 | 참고 기간 |
|--------------------------------|----------------|-----------|
| App Prototype | 1,000,000원부터 | 약 3–7일 |
| App Development | 2,500,000원부터 | 약 1–3주 |
| MVP Starter | 3,000,000원부터 | 약 1–2주 |
| MVP Standard | 4,500,000원부터 | 약 2–3주 |
| MVP Custom | 6,000,000원부터 | 별도 협의 |

공개 Business 패키지에 **Product MVP ₩3,000,000부터** 표기도 있음. **기능 수·관리자·푸시·결제 포함 여부에 따라 변동.**

### 가격 표현 (크몽용)
「앱 MVP는 범위에 따라 견적합니다. 사이트·패키지 **시작가(예: MVP 참고 300만원대부터)** 는 기본 범위 기준이며, **로그인+관리자+푸시 등 묶음은 확인 후 최종 견적**으로 안내합니다.」

### 포함 범위 (기본 합의 시)
합의된 화면·기능, 기본 수정 2회, 검수 기간(기본 5영업일), 30일 구현 오류 대응

### 별도 견적 항목
결제/구독·IAP, 실시간 채팅, 지도/GPS, 대규모 CMS, 다국어, 데이터 마이그레이션, 스토어 심사 대행·재제출, AI API 사용량, Design Only 전체 리디자인, 24h SLA

### 고객 준비사항
목적·Must 기능, 레퍼런스, 브랜드 자산(있으면), Apple/Google 계정 소유자, 도메인/Cloud 계정(해당 시)

### 배포 범위
빌드 산출물까지가 기본. TestFlight/스토어 제출·심사 대응은 **SoW에 포함 시에만**.

### 유지보수
30일 구현 오류 대응 후 건별/월간 별도.

### FAQ (요지)
- Q. 바로 확정가? → A. 아니오. Scope 후 견적.  
- Q. 디자인만? → A. Design Only는 별도 상품. 본 상품은 BUILD.  
- Q. 서버비? → A. 고객 부담 기본.

### 문의 전 확인 질문
1. iOS / Android / 둘 다  
2. Must 기능 Top 3  
3. 디자인 유무 (Figma 등)  
4. 관리자·푸시·결제 필요 여부  
5. 희망 일정·예산 감  
6. 스토어 출시 필요 여부  

상세 → `docs/client-projects/01-requirements-questionnaire.md`

## B. 웹사이트 / 웹 MVP 개발

### 서비스 제목 (예시)
반응형 웹사이트 · 웹 서비스 MVP 개발

### 한 줄 소개
랜딩을 넘는 다페이지·웹앱 형태의 서비스를 기획·UI·구현까지 구축합니다.

### 고객 대상
회사/브랜드 사이트, 회원·콘텐츠형 웹, 가벼운 SaaS 형태 MVP

### 제작 가능 범위
반응형 웹, 기본 인증·폼·CMS성 관리(합의 시), API/DB 연동(합의 시)

### 핵심 기능 예시
소개·서비스·문의, 회원, 게시/콘텐츠, 관리자, 결제(웹), SEO 기본(합의 시)

### 지원 플랫폼
Desktop / Mobile web

### 참고 시작가 · 기간
| 패키지 | 참고 시작 금액 | 참고 기간 |
|--------|----------------|-----------|
| Business Website | 1,200,000원부터 | 약 5–10일 |
| Web Service | 1,800,000원부터 | 약 1–3주 |
| (공개 표기) Website/Web Product | 1,200,000원부터 | — |

### 가격 표현
「웹사이트·웹 MVP는 **₩1,200,000부터(참고)** 이며, 페이지 수·회원·관리자·결제에 따라 **최종 견적**이 달라집니다.」

### 포함 / 별도 / 고객 준비 / FAQ
앱 MVP와 동일 정책(수정 2회, 외부 비용 고객, Scope 후 확정).  
별도: 대규모 CMS, 복잡한 권한, 검색엔진 마케팅 대행 등.

### 문의 전 확인 질문
목적(소개 vs 웹앱), 페이지/기능 수, 로그인·관리자, 호스팅/도메인, 일정·예산

|------|------|
