# Newon Studio 기본 정책 결정 기록 (내부)

**대상:** Newon 운영자  
**성격:** 내부 문서. Studio 외부 고객 프로젝트의 **기본 운영 정책**을 기록한다.  
**사용법:** 기본값은 아래 「결정」열을 따른다. 프로젝트 예외는 견적·SoW·계약([10](./10-client-project-agreement-template.md))에만 명시한다.

관련: [00 런북](./00-first-client-runbook.md) · [README](./README.md)

> 본 기록은 운영 기본값이다. 법률·세무·개인정보 자문을 대체하지 않는다.  
> 「전문가 검토」로 표시된 항목은 확정 법률 문구가 아니며, 필요 시 별도 검토 후 계약에 반영한다.

## 1. 결제 비율·시점

| 항목 | 내용 |
|------|------|
| **결정** | **소규모:** 총 계약금액 **300만원 미만 AND** 예상 작업기간 **4주 이하** → 계약금 **50%** / 잔금 **50%**. **중·대형/장기:** 총액 **300만원 이상** 또는 예상 **4주 초과** 또는 **중간 마일스톤 필요** 중 하나라도 해당 → 계약금 **40%** / 중도금 **30%** / 잔금 **30%** 적용 가능. 프로젝트 특성에 따라 견적·계약에서 **별도 조건** 가능. |
| **착수** | **계약금 입금 확인 후** 착수 |
| **중도금** | 사전에 합의한 **중간 마일스톤 완료 시** 청구. 보통 전체 작업 약 50% 단계. **단순 날짜가 아니라** 견적/SoW/계약에 구체 마일스톤 명시 |
| **잔금** | 최종 작업 및 합의된 검수/수정 절차 후 청구. **잔금 입금 확인 후** 합의된 최종 산출물 인계 |
| **예외** | 프로젝트별 견적·계약에 명시 시 가능 |
| **반영** | 02 · 10 · 04 · 05 |
| **상태** | **확정 (기본값)** |

## 2. 기본 수정 횟수

| 항목 | 내용 |
|------|------|
| **결정** | 기본 수정 **2회**. **1회** = 고객이 취합하여 전달한 **1회의 피드백 묶음**. 계약/SoW 범위 내 **경미한 수정**에 적용. **Newon 구현 오류** 수정은 2회에서 **차감하지 않음**. |
| **CR** | 신규 기능·페이지/화면·구조 변경·확정 방향의 대규모 변경·최초 Scope 밖 → Change Request (요청→Scope→비용/일정→안내→승인→작업). **승인 전 범위 밖 작업 금지** |
| **상세** | [06](./06-change-request-policy.md) |
| **예외** | SoW/계약에 별도 한도 명시 시 |
| **상태** | **확정 (기본값)** |
