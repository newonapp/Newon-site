## 5. 외부 서비스 비용 (기본: 고객 부담)

Newon **제작비**와 서비스 **지속 운영비**를 구분합니다.  
아래는 원칙적으로 **본 제작 견적에 포함되지 않으며 고객 부담**입니다. 포함 시 위 항목표에 명시합니다.

예: 도메인, 서버/호스팅, Firebase/Cloud, DB, 외부 API, AI API, 이메일/SMS, 결제 서비스, SaaS, 유료 Plugin/Asset, Apple/Google 개발자 관련 비용 등.

- 가능하면 **고객 명의 계정 + 고객 결제수단**을 사용합니다.  
- 사용량 기반 서비스 비용은 **고정 금액처럼 보장하지 않습니다**.  
- Newon이 불가피하게 선결제하는 경우: **고객 사전 승인 → 금액 확인 → 기록 → 정산**.  
- Newon 개인 결제수단에 고객 서비스 자동결제를 장기간 두는 것을 기본 운영으로 하지 않습니다.

## 6. 포함 / 미포함 (요약)

### 포함 (프로젝트에 맞게 수정)
- 합의된 범위의 기획·디자인·개발(해당 시)
- 기본 수정 **2회** (취합 피드백 1묶음 = 1회). 상세: [06](./06-change-request-policy.md)
- 고객 검수 기본 **5영업일** (무응답 ≠ 자동 승인)
- 납품 후 **30일** Newon 구현 오류 무상 대응 (SLA/24h 아님). 상세: SoW · [06](./06-change-request-policy.md)
- 합의된 최종 산출물 인계 (**잔금 입금 확인 후**)

### 미포함 (기본)
- SoW에 없는 신규 기능·페이지·구조 변경 → Change Request / 별도 견적
- 무제한 수정·상시 운영 대행·24시간 긴급 대응
- 외부 서비스 비용 (§5)
- 법적 자문, 세무, 개인정보 영향평가 대행
- Design Only 견적에 **개발(BUILD) 자동 포함되지 않음**

- □ **소규모** — 총 계약금액 **300만원 미만 AND** 예상 작업기간 **4주 이하** → 계약금 **50%** / 잔금 **50%**
- □ **중·대형/장기** — 총액 **300만원 이상** 또는 예상 **4주 초과** 또는 **중간 마일스톤 필요** → 계약금 **40%** / 중도금 **30%** / 잔금 **30%**
- □ **별도 합의** — 아래 표에 프로젝트 조건 기입

| 구분 | 비율 또는 금액 | 시점 |
|------|----------------|------|
| 계약금 | | 계약·합의 후 · **입금 확인 후 착수** |
| 중도금 | | 합의 마일스톤: **[구체명 — 예: 핵심 화면 구현 완료]** (단순 날짜만으로 두지 않음) |

| 기타 | | |

- VAT: §3 표시와 동일하게 정리  
- 세금계산서·현금영수증 등: **Newon의 실제 사업자 상태 및 거래 조건**에 따라 처리 (본 견적에서 세무 의무를 단정하지 않음)  
- 민감 정보(계좌 등)는 본 저장소 템플릿에 적지 말고 **실제 전달본**에만 기재합니다.
