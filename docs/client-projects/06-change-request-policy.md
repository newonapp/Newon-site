## 1. 기본 수정

### 정의

**기본 수정**이란, 이미 합의된 범위(SoW/계약) 안에서  
산출물의 **경미한 조정**(디자인·카피 소규모 변경, 명확성·일관성 개선 등)을 말합니다.

### 횟수·단위 (기본값)

| 항목 | 내용 |
|------|------|
| 기본 횟수 | **2회** |
| 1회의 의미 | 고객이 **취합하여 전달한 1회의 피드백 묶음** |
| 적용 | 계약/SoW **범위 내 경미한 수정** |
| Newon 구현 오류 | 아래 §2 — **2회에서 차감하지 않음** |

### 본 프로젝트 합의 (예외 시만 변경)

| 항목 | 합의 내용 |
|------|-----------|
| 범위 내 수정 한도 | 기본 **2회** / 예외: [ ] |
| 검수 기간 | 기본 **5영업일** / 예외: [ ] |
| 한도 초과 시 | Change Request · 별도 견적 |

## 2. Newon 구현 오류 (수정 횟수 비차감)

계약/SoW에서 합의한 기능이 **Newon의 구현 문제**로 정상 작동하지 않는 경우입니다.

**예:** 합의된 기능 미작동, 잘못된 동작, Newon 코드 문제, 합의된 로직 오류, Scope에 포함됐으나 구현 누락.

이러한 수정은 **기본 수정 2회에서 차감하지 않습니다.**  
납품 후 **30일** 무상 오류 대응 기간의 대상과도 같습니다 (§7).

---

## 3. Change Request (기본 수정이 아닌 것)

다음에 해당하면 기본 수정이 아니라 **Change Request**입니다.

- 새로운 기능  
- 새로운 페이지/화면  
- 구조 변경  
- 확정된 방향의 대규모 변경  
- 최초 Scope 밖 요구사항  

### 처리 절차

```
요청
 → Scope 확인
 → 비용/일정 영향 확인
 → 고객 안내
 → 고객 승인
 → 작업
```

**승인 전에 범위 밖 추가 작업을 먼저 진행하지 않습니다.**

| 단계 | 내용 |
|------|------|
| 1 | 요청 접수·기록 |
| 2 | 범위 내 / 범위 외 / 신규 분류 |
| 3 | 일정·비용 영향 안내 |
| 4 | 고객 승인 후 진행 또는 보류·다음 단계 이관 |
| 5 | 승인 시 SoW 부록·견적 보완 |

## 4. 범위 내 수정 (In-Scope) 예시

| 예시 | 처리 |
|------|------|
| SoW에 명시된 기능의 버그·오동작 (Newon 구현) | 우선 수정 · **횟수 비차감** |
| 합의된 시안 내 간격·정렬·오탈자·소규모 카피 조정 | 기본 수정 한도 내 |
| 검수 기간 중 Critical / Major 결함 | 납품 전 해결 목표 |

## 5. 일정에 영향을 주는 경우

다음이 있으면 납품일이 달라질 수 있습니다.

- Change Request 승인  
- 고객 자료·피드백·승인·계정·권한 지연  
- 외부 계정·심사·서드파티 장애  
- 중대한 기술·보안 이슈 발견  

고객 지연은 Newon 작업 지연과 **구분**합니다.  
무응답 5/10/30 기준은 [05-project-guide.md](./05-project-guide.md)를 따릅니다. (**자동 승인·자동 종료 아님**)

변경 시 Newon은 **조정된 일정안**을 공유합니다.

---

## 6. 추가 비용이 발생할 수 있는 경우

실제 금액은 건별 견적합니다.

- Change Request (신규 기능·페이지·구조 변경 등)  
- 합의된 수정 한도(기본 2회) 초과  
- 추가 플랫폼·언어·환경  
- 유료 API·SMS·스토어·라이선스 등 **외부 비용** (부담 주체는 견적 [02](./02-quote-template.md) 기준, 고객 부담이 기본)  
- 긴급 투입·야간·주말·**24시간/SLA** (사전 별도 합의 시에만)  
- **30일 이후** 유지보수·추가 작업  

---

## 7. 30일 Newon 구현 오류 대응 vs 유지보수

| 구분 | 내용 |
|------|------|
| 30일 무상 | 인수 확인일 **다음날부터 30일**(합의된 납품/운영일 예외 가능). **Newon 구현 오류**만. 시작·종료일은 인수서에 기록 |
| 무상 아님 | 신규 기능·페이지·디자인 변경·요구 변경·기능 방식 변경·신규 연동·고객/제3자 수정으로 생긴 문제·고객 설정·고객 제공 데이터/콘텐츠·제3자 서비스 자체 장애/정책 변경. 단, Newon이 잘못 설정/구현한 경우는 구현 오류 여부 확인 |
| SLA | 30일 대응 ≠ **24시간 상시/SLA**. 긴급·SLA는 별도 합의 |
| 30일 이후 | 건별 유지보수 · 월 유지보수 · Change Request · 별도 프로젝트 |
