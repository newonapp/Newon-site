## 11. 검수 기준

- 검수 기간: 각 전달(또는 최종 검수 안내) 후 기본 **5영업일**  
- 피드백: 가능한 한 **취합**하여 전달  
- 검수 방법: [체크리스트 / 스테이징 URL / 빌드 등]  
- **합격 기준:** SoW In Scope 기능이 합의된 환경에서 동작하고, Critical 결함(사용 불가·데이터 손실·보안 사고성)이 없을 것  
- Scope 내 문제 → 수정. 신규 요구사항 → Change Request  
- **고객 무응답만으로 자동 승인 처리하지 않음**  

상세 납품 점검은 [07-delivery-checklist.md](./07-delivery-checklist.md)를 내부적으로 사용합니다.

## 13. 30일 Newon 구현 오류 대응

- 원칙: 고객 **최종 인수 확인일 다음날부터 30일**  
- 인수 확인 없이 먼저 운영되는 경우: 합의된 **최종 납품일 또는 운영 시작일** (본 SoW/인수서에 기록)  
- 대상: 계약/SoW 합의 기능이 Newon **구현 문제**로 정상 작동하지 않는 경우  
- 비대상: 신규 기능·디자인/요구 변경·고객·제3자 수정·고객 설정/데이터·제3자 서비스 자체 장애 등 (상세 [06](./06-change-request-policy.md))  
- **24시간 상시 대응/SLA를 의미하지 않음.** 긴급·SLA는 별도 합의  
- 30일 이후: 건별/월 유지보수, CR, 별도 프로젝트 등  

시작일 [ ] · 종료일 [ ] (인수 시 [08](./08-acceptance-form.md)에 확정 기록)
