## 7. 고객 제공사항 및 협조

고객은 합의된 기한 내에 자료·콘텐츠·계정·권한·피드백·승인을 제공합니다.  
지연 시 일정은 조정될 수 있으며, Newon의 작업 지연과 구분합니다.  
가능하면 고객이 서비스 계정을 소유하고, Newon에는 필요 기간 **최소 권한**만 부여합니다.

## 9. Change Request

신규 기능·페이지/화면·구조 변경·확정 방향의 대규모 변경·최초 Scope 밖 요구는 Change Request입니다.

절차: 요청 → Scope 확인 → 비용/일정 영향 → 고객 안내 → **고객 승인** → 작업.  
**승인 전 범위 밖 작업을 진행하지 않습니다.**  
Scope 변경은 중도 취소가 아니라 Change Request로 우선 처리합니다.

## 10. 검수 (기본 5영업일)

- 기본 검수 기간 **5영업일**  
- 피드백은 가능한 한 취합하여 전달  
- Scope 내 문제 → 수정 / 신규 요구 → Change Request  
- **고객 무응답만으로 자동 승인하지 않음**

## 11. 고객 지연 / 무응답 (5 · 10 · 30)

| 경과 | 처리 |
|------|------|
| **5영업일** | 진행 확인 및 필요 자료/피드백 재안내 |
| **10영업일** | 프로젝트 **일시 보류 가능**. 기존 납품 예정일 유지 **보장하지 않음** |
| **30일 이상** | 계약·진행률·완료 작업·발생 비용을 확인해 **종료 및 정산 절차 검토 가능** |

- 무응답 ≠ **자동 승인**  
- 30일 ≠ **자동 종료**  
- 보류 후 고객 복귀 시: Newon의 **현재 작업 일정** 기준으로 재개일·납품일 재협의

## 12. 중도 취소 / 정산 (운영 초안)

> **전문가 검토가 필요한 영역입니다.** 아래는 기본 운영 초안이며, 법률적 확정 문구가 아닙니다.  
> 「계약금은 어떠한 경우에도 환불 불가」와 같은 **절대 문구를 사용하지 않습니다.**

기본 방향:

- 실제 **완료된 작업**과 실제 **발생 비용**을 기준으로 정산  
- 프로젝트 시작 전/후, 진행 단계, **귀책 사유**(고객 / Newon)를 구분하여 고려  
- Newon이 **제공하지 못한 작업**에 대한 비용을 무조건 청구하는 구조로 운영하지 않음  
- Scope 변경은 취소가 아니라 **Change Request**로 우선 처리

## 15. 제3자 서비스 및 외부 비용

- Newon **제작비**와 서비스 **지속 운영비**를 구분합니다.  
- 도메인·서버·Cloud·DB·API·AI·이메일/SMS·결제·SaaS·유료 Plugin/Asset·개발자 계정 등은 **원칙적으로 고객 부담**입니다.  
- 가능하면 **고객 명의 계정 + 고객 결제수단**.  
- 사용량 기반 비용은 고정 금액처럼 보장하지 않습니다.  
- Newon 선결제 시: 고객 사전 승인 → 금액 확인 → 기록 → 정산.  
- Newon 개인 결제수단에 고객 서비스 자동결제를 장기간 두는 것을 기본으로 하지 않습니다.  

상세 예: [02-quote-template.md](./02-quote-template.md) §5.

## 16. 계정 / Secret / 고객 데이터

- 가능하면 고객이 서비스 계정 소유 · 고객 결제수단 사용  
- Newon은 필요 기간 **최소 권한** · 비밀번호 공유보다 **초대/권한 부여** 우선  
- Secret / API Token / 비밀번호를 일반 문서·코드·공개 저장소에 **평문 저장하지 않음**  
- 환경변수 / Secret Manager 등 적절한 방식 사용  
- 프로젝트 종료 후 불필요한 Newon 접근 권한 및 Secret **정리**  
- 테스트는 실제 개인정보가 불필요하면 **테스트 데이터 우선**  
- 개인정보를 직접 처리하는 프로젝트는 **별도 개인정보/처리위탁 검토가 필요할 수 있음** (**전문가 검토 권장**)
